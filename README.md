# IronForge

IronForge is a Flutter-based workout tracking application designed to help users log exercises, track sets and reps, and review workout history.

## Features
- Add exercises
- Add workout sets
- Delete exercises and sets
- Workout history tracking
- Session detail view
- lbs / kg support
- Firebase integration setup

## Tech Stack
- Flutter
- Dart
- Firebase
- Cloud Firestore (planned persistence layer)

## Future Improvements
- Persistent cloud storage
- User authentication
- Workout analytics
- Cross-device syncing
